# MCP-Pi Gateway 1.3.2

> Patch release hardening self-restarting maintenance and deployment control-plane recovery.

## Scope

1.3.2 prevents long maintainer operations from depending on the same MCP/Tunnel session they intentionally restart. No Core API, Bridge API, Registry schema or Tool Catalog version changes are introduced.

Key changes:

- `deploy-pi.sh` fails closed unless launched by `scripts/run-resumable.sh`;
- `MCP_DEPLOY_ALLOW_DIRECT=1` is retained only as an explicit break-glass recovery override;
- the runner exports a non-secret resumable job identity to child processes;
- deployment and rollback logs delimit expected control-plane outages with `CONTROL_PLANE_RESTART=EXPECTED` and recovery with `CONTROL_PLANE_RESTORED`;
- reconnect guidance requires `status` + `log` + real runtime verification before any retry;
- the interactive `run_command` default remains 30 seconds; long or self-restarting work belongs in the resumable runner.
