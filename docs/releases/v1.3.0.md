# Software Baseline Notes: MCP-Pi Gateway 1.3.0

**Status:** current `develop` / production software baseline. **No immutable `v1.3.0` tag is created by this mission; `v1.2.1` remains the latest immutable tag.**

## Scope

1.3.0 is a SemVer minor because it adds public capabilities and controls while preserving Core/Bridge API v1, Tool Catalog v3 and Registry Schema v1.

- structured filesystem confinement uses remote canonical destination resolution and rejects symlink escapes;
- `run_command` is a trusted Target shell controlled by `shell_enabled` and explicit `target_shell`/compatible grants;
- `run_task` remains the preferred allowlisted repeatable execution path;
- critical audit writes fail closed where execution without an audit record would be unsafe;
- MCP tools expose standard annotations and deterministic catalog metadata;
- Target status exposes lightweight Environment Facts with `unknown`/`unavailable` when facts cannot be verified;
- systemd hardening is incremental and measured;
- deployment is exact-commit, candidate-based, rollback-capable and records verified provenance;
- CI and documentation audits reproduce the development gates;
- private appliance backups support optional `age` encryption without making it a Core dependency.

The definitive deployed SHA is `.deployment.json.commit`; production acceptance must prove it equals local `HEAD` and `origin/develop`.
