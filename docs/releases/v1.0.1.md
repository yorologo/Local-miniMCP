**Release Date:** September 2026

## 1. Summary

MCP-Pi Gateway `v1.0.1` is a maintenance patch release focused exclusively on metadata hygiene, documentation obsolescence removal, and example configuration cleanup following the `v1.0.0` stable release.

No architecture or protocol contracts were modified.

## 2. Changes Included

  - `compatibility.json`
  - `src/mcp_gateway/__init__.py`
  - `src/mcp_gateway/compatibility.py`

- Updated test expectations to match `1.0.1`:
  - `tests/test_bridge.py`

### Target Configuration Example Hygiene
- `config/targets.example.json`:
  - Replaced environment-specific IP addresses (`192.168.68.84`, `192.168.68.100`) with generic RFC 1918 example addresses (`192.168.1.50`, `192.168.1.100`).
  - Formalized that target host IP is a mutable runtime endpoint while `target_id: termux-main` and its SSH host key fingerprint (`SHA256:qILA9dmqZNJS7PaxqDtC7weR4NdcGhruxsUYHpPish0`) provide cryptographic identity pinning.

### Alias Audit
- Audited `pc-local` alias:
  - Preserved backward-compatible SSH alias (`Host termux-local pc-local`) in SSH configurations.
  - Standardized all documentation and tool definitions on `termux-main` as target ID and `termux-local` as the primary SSH alias.

### Documentation Overhaul
- `README.md`:

  - Updated tool status table (`write_file` ACTIVE, `apply_patch` DEFERRED).

  - Documented production baseline on Raspbian 11 (Bullseye) 32-bit ARMv6 and deferred Trixie migration post-v1.
