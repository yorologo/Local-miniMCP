# MCP-Pi Gateway 1.3.1

> Patch release for the repository/project rename and release branding cleanup. The immutable `v1.3.1` tag on `main` is the authoritative release identity.

## Scope

1.3.1 standardizes the public project name as **MCP-Pi** without changing the gateway architecture or security model.

Key changes:

- canonical repository name and URL use `yorologo/MCP-Pi`;
- public documentation and source branding use `MCP-Pi`;
- release bundle filenames use the `MCP-Pi-` prefix;
- CI validates the renamed bundle pattern;
- Gateway/runtime version is bumped from 1.3.0 to 1.3.1.

Compatibility-preserving internal identifiers such as `LOCAL_MINIMCP_STATE_DIR` and `~/.local/state/local-minimcp/` intentionally remain unchanged so existing resumable jobs and automation do not break.

## Compatibility

```text
Gateway: 1.3.1
Core API: 1
Bridge API: 1
Tool catalog: 3
Registry schema: 1
MCP: 2026-07-28
Python: 3.9+
```

There are no intentional breaking API, schema, policy, or data-format changes from 1.3.0.

## Release acceptance

The release commit must pass the complete local/CI gates, ARMv6 bundle validation, exact-commit production deployment, Doctor/endpoints/Target/provenance acceptance and documentation audit on the same SHA before `v1.3.1` is created.

Do not duplicate the accepted SHA in prose; use `git rev-parse 'v1.3.1^{commit}'` or runtime provenance as the source of truth.
